# React Native 기능 개발 절차

## 1. 요구사항 확인
- `docs/APP_SPEC.md`의 관련 요구사항과 기존 코드를 확인한다.
- 기능의 입력, 출력, 사용자 동작 및 오류 상황을 정리한다.
- 요구사항이 불명확하면 사용자에게 질문한다. 미결정 항목을 임의로 정하지 않는다.

## 2. 구현 계획
- 변경할 파일과 각 파일의 역할을 설명한다.
- 기존 구조를 최대한 유지한다. (화면 `src/app/`, 재사용 UI `src/components/`, 저장 `src/storage/`)
- 새로운 라이브러리가 필요한지 검토하고, 필요하면 설치 전에 승인을 받는다. (`npx expo install` 사용)
- 데이터 저장이 필요하다면 기존 저장 구조와의 호환성을 확인한다.

## 3. 구현
- TypeScript 타입을 명확하게 정의한다.
- UI와 데이터 처리 로직을 적절히 분리한다. 화면에서 저장소를 직접 호출하지 않는다.
- 로딩, 오류, 빈 데이터 상태를 고려한다.
- 불필요한 추상화와 중복 코드를 피한다.

## 4. 검증
- `npx tsc --noEmit`을 실행한다. lint는 설정되어 동작하는 경우에만 실행한다. (현재 eslint 미설치)
- 개발 서버 포트는 8082다. `npm run ios` / `npm run android`를 사용한다.
- 저장 기능이 있다면 저장 후 재조회 및 앱 재시작 후 유지 여부를 검증한다.
- iOS와 Android를 각각 확인하고 결과를 구분해 보고한다.
- 검증하지 못한 항목을 명확하게 보고한다.

## 5. 완료 보고
- 변경된 파일
- 구현된 기능
- 실행한 테스트와 결과 (실행하지 않은 것은 실행하지 않았다고 표시)
- 남아 있는 문제 및 후속 작업

을 간결하게 정리한다.
