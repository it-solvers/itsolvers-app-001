# 진행 상황

마지막 갱신: 2026-10-16 (마지막 커밋 기준은 `git log` 참고). 작업을 마칠 때마다 이 문서를 고친다.
앱 동작은 `APP_SPEC.md`, 구조와 결정 이유는 `ARCHITECTURE.md`에 있다. 여기에는 **상태와 다음 할 일**만 적는다.

## 완료한 것
- 제조사(현대) → 차종 → 트림 → 사양·옵션·색상 선택, 가격 합계, 옵션 간 제약(실시간 조회)
- 가격 하루 1회 JSON 저장(오프라인 대비 stale 표시), 로딩·오류·재시도
- "차량 선택 완료" 화면: 차량 정보, 차량가격, 리스료 계산(기간, 선수금·보증금·잔존가치는 금액 직접 입력 + 비율 슬라이더(5% 단위, 0~90%, 손잡이 위 확대 글자), 금리 입력, 월 납입금액)
- 견적 글자 공유(공유창/웹은 복사). 이미지 저장·공유는 하지 않기로 함
- 제조사 화면의 "차량가격 직접 입력"(차량 정보 없이 차량가격부터 입력)
- 이미지: 차량 카드, 제조사 엠블럼, 색상 동그라미 (현대 사이트에서 실행 중 불러옴, 저장소에 복사하지 않음)
- 웹 배포(Vercel): 시작 화면만 검색 노출, 나머지 noindex, 공유 미리보기(OG)·파비콘·sitemap·구글 소유권 확인
- 모든 화면 "학습용" 배너, 시작·제조사 화면에 회사 로고 헤더, 시작 화면에만 푸터(회사 정보+저작권), 이후 화면 제목줄 오른쪽에 작은 회사 로고

## 직접 확인하지 못한 것 (검증 범위)
- 실제 폰(Android/iOS 실기기)에서의 동작
- iOS 터치 동작(시뮬레이터는 명령으로 터치를 보낼 수 없음). 화면 표시만 확인함
- 웹 브라우저에서의 실제 화면과 마우스 조작
- 견적 공유: Android 공유창 열림만 확인함(카카오톡 등으로 실제 보낸 결과, iOS, 웹 복사는 미확인)
- 비율 슬라이더의 화면 낭독(접근성) 조절, 웹 마우스 끌기
- 선수금+보증금이 차량가격을 넘는 조합의 오류 문구를 화면에서 눌러 본 것
- 차량 선택 흐름(직접 입력이 아닌 경로)에서의 금액 입력 칸 (직접 입력 경로만 확인함)
- 텔레그램 공유 미리보기 (서버 응답은 정상. 저장된 미리보기 때문일 수 있음)

## 알려진 문제와 주의
- 현대 가격 API는 공식이 아닌 내부 주소라 구조가 바뀌면 멈출 수 있다. 약관, 엠블럼·이미지 상표 문제는 스토어 출시 전에 판단해야 한다.
- 금액은 학습용 참고값이며 실제 구매 가격과 다를 수 있다.
