# APP_SPEC.md

## 1. 문서 목적

본 문서는 iOS 및 Android용 개인 유틸리티 앱(itsolvers-app-001)의 요구사항을 정의한다.

현재는 프로젝트의 기본 기술 방향만 정해졌으며, 구체적인 앱 기능은 사용자와 협의하여 확정한다.

## 2. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | itsolvers-app-001 |
| 앱 유형 | 일반 유틸리티 |
| 지원 플랫폼 | iOS, Android |
| 프레임워크 | React Native + Expo SDK 57 |
| 프로그래밍 언어 | TypeScript |
| 데이터 저장 | 기기 내부 저장 |
| 백엔드 | 없음 |
| 사용자 인증 | 현재 계획 없음 |
| 배포 | 개인용 또는 내부 테스트 |

## 3. 앱의 목적

- 구체적인 해결 대상: **미정**
- 주요 사용자: 개인 사용자
- 핵심 사용 시나리오: **미정** (사용자와 협의 후 결정)
- 성공 기준: **미정** (핵심 기능과 검증 방법을 협의 후 결정)

## 4. 기능 명세

아래 항목은 아직 확정되지 않았다.

- [ ] 핵심 기능
- [ ] 데이터 입력 및 수정
- [ ] 데이터 조회 및 검색
- [ ] 데이터 삭제
- [ ] 설정 화면
- [ ] 데이터 내보내기 및 가져오기
- [ ] 백업 및 복원

실제 요구사항에 필요한 기능만 선택한다. 모든 항목을 무조건 구현하지 않는다.

## 5. 화면 구성

화면 목록은 핵심 기능이 확정된 뒤 결정한다. (현재 앱에는 Expo 템플릿 예제 화면 Home/Explore만 있으며 실제 기능이 아니다.)

각 화면의 명세에는 다음 항목을 포함한다.

- 화면 목적
- 표시할 데이터
- 사용자 입력
- 사용자 동작
- 오류 및 빈 상태
- 다른 화면과의 이동 관계

## 6. 데이터 및 저장 정책

- 데이터는 원칙적으로 기기 내부에 저장한다.
- 앱을 종료하고 다시 실행해도 저장된 데이터가 유지되어야 한다.
- 저장 방식은 데이터의 복잡성과 규모에 따라 결정한다. (**미정**)
- 앱 삭제, 기기 변경, 데이터 초기화 시 데이터가 어떻게 되는지 사용자에게 명확히 안내한다.
- 백업 및 복원 기능은 별도 요구사항으로 확정하기 전까지 지원한다고 가정하지 않는다.
- 외부 서버로 사용자 데이터를 전송하지 않는다.

## 7. 비기능 요구사항

- iOS와 Android에서 핵심 기능이 동일하게 동작해야 한다.
- 일반적인 화면 크기와 시스템 글자 크기를 고려한다.
- 사용자 입력을 검증하고 오류를 이해하기 쉽게 표시한다.
- 앱의 핵심 기능은 네트워크 연결 없이 사용할 수 있도록 설계한다.
- 데이터 손실을 방지하고 저장 실패를 적절히 처리한다.
- 초보 개발자가 유지보수할 수 있도록 구현을 단순하게 유지한다.

## 8. 테스트 기준

- 신규 데이터 저장
- 저장 데이터 조회 및 수정
- 데이터 삭제
- 앱 재시작 후 데이터 유지
- 입력 오류 및 저장 오류 처리
- iOS 및 Android 플랫폼별 주요 동작 확인

실제 테스트 항목은 확정된 기능에 맞춰 조정한다.

## 9. 미결정 사항

다음 항목은 사용자와 협의한 후 확정한다.

- 앱의 구체적인 목적
- 핵심 기능 및 우선순위
- 필요한 화면
- 데이터 종류와 저장 구조
- 검색 및 정렬 요구사항
- 데이터 내보내기와 백업 필요 여부
- 지원할 최소 OS 버전
- 테스트 기기와 배포 방식

## 10. 개발 범위 관리

최초 버전은 가장 중요한 기능만 포함하는 MVP로 개발한다.

사용자가 승인하지 않은 기능, 외부 서비스, 유료 서비스, 분석 도구는 임의로 추가하지 않는다.

기능 명세가 변경되면 본 문서를 먼저 갱신하고 구현에 반영한다.
